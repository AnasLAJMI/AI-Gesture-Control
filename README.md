# 🖐️ AI Gesture Control

**Control your computer using hand gestures with Artificial Intelligence and Computer Vision.**

AI Gesture Control is a Python-based project that uses a webcam to detect and recognize hand gestures in real time. It allows users to interact with their computer through natural hand movements.

## ✨ Features

- 🤚 Real-time hand detection.
- 🎯 Hand landmark tracking.
- 🖱️ Virtual mouse control using hand gestures.
- 📊 PowerPoint presentation control.
- 🤖 Gesture recognition using MediaPipe.
- 📷 Live camera processing.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| MediaPipe | Hand detection and tracking |
| OpenCV | Image processing and webcam access |
| PyAutoGUI | Mouse and keyboard automation |
| NumPy | Numerical operations |

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/AnasLAJMI/AI-Gesture-Control.git
```

### 2. Navigate to the project directory

```bash
cd AI-Gesture-Control
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment (Windows)

```bash
venv\Scripts\activate
```

### 5. Install the required libraries

```bash
pip install mediapipe opencv-python pyautogui numpy
```

## ▶️ Running the Project

Run the desired Python script:

```bash
python hand_detection.py
```

Other modules include:

- `gesture_recognition.py`
- `virtual_mouse.py`
- `powerpoint_control.py`

Make sure your webcam is connected and accessible.
